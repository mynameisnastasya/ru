@Threads Autopilot Setup

Подключение за один проход.

Импортируй готовый workflow в n8n, назначь два credentials, активируй его и вставь production webhook сюда. После проверки настройки автоматически попадут в основную панель.

1

Скачай workflow

Готовый файл лежит прямо в этом репозитории.
Скачать JSON Открыть на GitHub ↗
2

Импортируй в n8n

В n8n: Workflows → Import from File → выбери скачанный JSON.
3

Назначь credentials

Для OpenAI назначь Header Auth с Authorization: Bearer YOUR_OPENAI_KEY. Для Threads — Header Auth с Authorization: Bearer YOUR_THREADS_TOKEN. Сами ключи в GitHub не добавляй.
В workflow включён Dry run по умолчанию. Сначала проверяй генерацию и ответы без реальной публикации.
4

Активируй workflow и скопируй Production URL

Открой Webhook node Threads Controller и скопируй именно Production URL, не Test URL.
5

Подключи панель

Открыть панель
Готов к проверке.
