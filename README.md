# GuruDreads — editorial concept site

A responsive one-page concept for GuruDreads, built around the brand language visible in the supplied Instagram references: loose-end dread extensions, tonal ombré work, raw wood, dried botanicals, linen and earthy neutrals.

## Direction

- Premium editorial rather than generic hair-store UI
- Signature focus on loose ends, movement and colour blending
- Interactive custom-order brief builder
- Mobile-first responsive layout
- Direct Instagram and store calls to action
- Lightweight vanilla HTML/CSS/JS with no framework dependency

The site entry point is `index.html` and is ready for GitHub Pages.
