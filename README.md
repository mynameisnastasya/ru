# Threads Autopilot — demo website

Однофайловый статический лендинг.

## Запуск
Просто откройте `index.html` в браузере.

## Что внутри
- responsive dark UI
- hero + dashboard mockup
- схема публикации и автоответов
- Threads API flow
- правила автоответов
- контент-микс
- feedback loop
- базовый промпт для LLM

Никаких внешних зависимостей.
