Генерация постов, публикация, синхронизация replies, аналитика и полный цикл запускаются прямо отсюда через твой n8n production webhook.

Threads/OpenAI access tokens сюда не вставляй. Они должны храниться в credentials n8n. В панели сохраняются только URL управляющего webhook и необязательный токен доступа к самому webhook.

Контракт webhook

В n8n Webhook → Switch по полю action.
POST {WEBHOOK_URL} Content-Type: application/json { "action": "generate_post", "source": "threads-autopilot-dashboard", "timestamp": "ISO_DATE", "account": "my_threads", "options": { "autoPublish": false, "autoReplies": false, "dryRun": true }, "payload": { "topic": "...", "draft": "..." } }
GitHub Pages — только панель. Секреты, Threads API, OpenAI и расписания выполняются на стороне n8n.
