# Временная заглушка WINK

В этой ветке деморежим включён по умолчанию. Это не замена серверу для реальных продаж.

- Каталог композиций использует локальный прайс v6. Дополнения используют отдельные синтетические записи с `demo-` / `DEMO-` идентификаторами, условными ценами и остатками. Фото отсутствуют и явно обозначены заглушками.
- Работают выбор, максимум три рекомендации, быстрый просмотр, персонализация, набор SOFT TOUCH, подтверждение замены пересекающихся позиций, отдельные строки и пересчёт корзины.
- Оформление проверяет состав, количество, персонализацию и срок изготовления локально. Результат прямо сообщает «Заказ не отправлен». Доставка не рассчитана. Никаких платежей, резервов, списаний, CRM/Telegram-уведомлений или событий коммерческой аналитики нет.
- Тестовая корзина и пожелания по доставке имеют отдельные ключи браузерного хранилища. Реальная корзина и ссылка на предыдущий заказ не изменяются. Контактные данные формы не сохраняются и не отправляются.
- Остатки являются неизменяемыми тестовыми данными, а не общим складом. Проверка одновременной продажи и вебхуков возможна только после подключения сервера.
- Админка остаётся настоящей, с прежней авторизацией; её серверная интеграция не подменена. Эта заглушка предназначена для покупательского сценария.
- Страницы демосборки помечены `noindex, nofollow`.

Для реального режима установить `NEXT_PUBLIC_WINK_DEMO=false` **до сборки**. Без повторной сборки режим не меняется. Ошибка настоящего API никогда не переключает сайт на фиктивное успешное оформление. До включения реальных продаж выполнить все серверные условия из `RELEASE_NOTES_WINK.md` и `backend/addons/README.md`. Тестовые записи в production не импортировать.
